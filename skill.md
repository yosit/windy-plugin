# Windy skill

The authoritative, packaged skill is [`skills/windy/SKILL.md`](skills/windy/SKILL.md).

Windy is migrating to a single `@yosit/windy` package containing its shared client, Runline adapter, Dripline adapter, and agent skill. The old weather CLI is removed. Authentication is configured on the host connection, not through login/token shell commands.
